# Демо-сайт «Больше токенов с каждой GPU»

Локальный демо-сайт для кодовых ассистентов: показ на проекторе, запись клипов и gif для слайдов инвесторской презентации.
Чистые ES-модули, **без сборки и без сети**: шрифты лежат в `fonts/`, внешних запросов нет (проверено, см. «Проверки»).

> Все числа на экране — **расчёт по модели производительности, а не замер на GPU**. Плашка-дисклеймер есть на каждой сцене
> (слева внизу); сайт нигде не называет реальные компании-конкуренты и не утверждает «мы сжимаем всё».

## Запуск

```bash
cd demo-site
python -m http.server 8765 --bind 127.0.0.1
```

Откройте <http://127.0.0.1:8765/>. Холст логический 1920×1080 и масштабируется под окно (проектор 16:9 — на весь экран).
Файл можно открывать только через http (ES-модули не работают с `file://`).

## Параметры URL

| Параметр | Значение | Смысл |
|---|---|---|
| `scene` | 1, 2, 3, 4, 5, 7, 8, 9, 10 | сцена |
| `case` | `gallery`, `a0`…`a4`, `b1`…`b4`, `c1`…`c4` | галерея или страница кейса |
| `tour` | `short`, `full`, `qa` | маршрут по кейсам (←/→ или пробел/клик) |
| `mode` | `hint`, `chat`, `agent` | режим для сцены 1 |
| `load` | 0.3–1.2 | нагрузка ρ подобранной стороны |
| `seed` | число | сид ГПСЧ (mulberry32); тот же сид — тот же ролик |
| `bursty=1`, `burstAt=<с>` | | всплеск трафика / принудительный всплеск в момент `burstAt` |
| `theme` | `investor` (по умолчанию), `grant` | цветовая схема |
| `record=1`, `duration=<с>` | | режим записи: виртуальное время, без управляющих элементов |
| `profile`, `step`, `routing`, `growth` | | стартовое состояние сцен 4, 7, 8, 5 |

Клавиши: **←/→** — предыдущая/следующая сцена или кейс, **1 2 3** — режим, **пробел** — пауза, **R** — заново, **G** — галерея кейсов, **S** — сцены.

## Сцены

1. Тот же GPU — вдвое-втрое больше разработчиков: split view, 12 мини-IDE на сторону, полезные и сырые ток/с, «Стендап закончился».
2. Подсказка, которая опоздала (дедлайн 0,6 с).
3. Агент: где тратится время (префилл vs декод).
4. Микшер профиля с барицентрическим селектором.
5. **Одна нода** (вместо «800 карт»): целые ноды, слайдер +0…+100 %, формула `20 / 1,25 = 16`, счётчик переплаты.
6. **Не сделана намеренно**: в ТЗ она требует `src/scenarios.json`, которого нет, числа не выдумываем.
7. 27 648 конфигураций → одна: 5 шагов, затем смена профиля.
8. Один репозиторий — один кэш: политики маршрутизации.
9. Отчёт приёмки (демонстрация формата).
10. Полгода партнёрства (таймлайн).

Кейсы (`demo_cases.md`): группа A — сценарии нагрузки (A0–A4), B — как потратить прирост (B1–B4), C — роутинг (C1–C4).
В группе C нет рублей и множителей «×N»; бейдж «иллюстрация» никогда не стоит рядом с рублями.

## Запись клипов

Запись покадровая и детерминированная (виртуальное время, симуляция идёт строго 60 Гц), поэтому не зависит от мощности машины.

```bash
npm i --no-save playwright && npx playwright install chromium   # один раз
node record.mjs --list                  # готовые клипы
node record.mjs clip_hint_split         # один клип
node record.mjs --all                   # все
node record.mjs clip_mixer --gif        # + gif 1280 px
node record.mjs --check clip_ghost_late # записать дважды, сравнить кадры побайтно
```

Разрешение 2560×1440 (1920×1080 × `deviceScaleFactor` 4/3), 30 fps. Кодирование: если в PATH есть **ffmpeg** — он;
иначе автоматически `encode.py` (Python: `pip install av pillow`; PyAV приносит свой x264, Pillow собирает gif).
mp4 — H.264 yuv420p, открывается в PowerPoint. Если не сработало ничего, PNG-кадры остаются в `clips/<имя>/frames/`
(каталог `clips/` в `.gitignore`). Кодировщик можно запускать и вручную:
`python encode.py clips/<имя>/frames clips/<имя>/<имя> --fps 30 --gif`.

## Допущения и отклонения от брифов

Всё, что не следует из брифов дословно, помечено в коде как `[ДОПУЩЕНИЕ ДЕМО]`. Главное:

- **Модель обслуживания.** Processor-sharing, шаг 1/60 с, один поток запросов на обе стороны; префилл — задержка допуска
  (ёмкость не меняется); «полезный» токен зачитывается по состоянию SLA (подсказка позже 0,6 с — не полезна).
  Всплески — MMPP (k=3, 8 с всплеска / 25 с затишья, среднее сохраняется).
- **Параметры режимов** (`sim.js`, `MODES`): чат G=6/B=48, агент G=12/B=24; SLA агента — множитель 2,0 к «идеальному»
  времени ответа (в брифе 1,5) — подобрано при настройке под целевые 46 → 76 ток/с на GPU.
- **MTP на экране** (связки токенов 1–3) — только визуализация, на расчёт не влияет.
- **Цена ноды:** публичная ставка аренды, «от» 3 815 625 ₽/мес за 4×H200 (источник — бриф; провайдер в подписи
  не называется). Любая замена источника — в `data.js` (`HEADLINE.costBasis`).
- **Облако конфигураций** (сцена 7, кейс C4) — синтетическое, откалибровано под множители режимов; на C4 числа не показываются
  («после замеров»).
- Кодирование проверено через `encode.py` (PyAV + Pillow) на 3-секундном клипе сцены 5: mp4 H.264 2560×1440, gif 1280×720.
  Путь через системный ffmpeg не проверялся (его на машине нет). Детерминизм кадров проверен для девяти клипов
  (`--check`, 120 кадров, побайтно).
